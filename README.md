# FlowDesk — SaaS Landing Page

A sleek, dark **SaaS landing page** for a fictional project-management tool, built as a
portfolio piece to show modern product-marketing UI and attention to detail.

🔗 **[Live demo →](https://flowdesk-9rpinymg8-hazard-team.vercel.app)**

![FlowDesk preview](https://image.thum.io/get/width/1200/https://flowdesk-9rpinymg8-hazard-team.vercel.app)

## The brief
A SaaS startup needs a landing page that looks like a real, premium product (think
Linear / Stripe / Vercel): clear value proposition, a believable product preview,
features, social proof and transparent pricing.

## What I built
- **Hero** with a detailed in-browser **app mockup** (sidebar, sprint board, kanban)
- Alternating **feature blocks**: animated ⌘K command menu, an SVG **analytics chart**, a discussion thread
- **Feature grid**, logo wall, **3-tier pricing** with a highlighted plan
- **Testimonials**, an accordion **FAQ** (native `<details>`), and a final CTA
- Dark theme, gradient accents, micro-interactions; fully responsive

## Tech
- **HTML5**, **CSS3** (grid, flexbox, gradients, backdrop-filter)
- **Vanilla JavaScript** — sticky header, smooth scrolling, FAQ
- Google Fonts (Inter + JetBrains Mono) · no build step

## Run locally
It's a static site — just open `index.html` in your browser.

```bash
git clone https://github.com/L1nkBl1nk/flowdesk.git
cd flowdesk
# then open index.html
```
